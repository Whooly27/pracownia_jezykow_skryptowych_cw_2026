# Upload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Domena zgodna ze spec z 7.11 (płaskie pliki, trzy uprawnienia, dostęp tylko przez linki) plus działający upload: `POST /uploads`, `POST /uploads/{id}/complete`, `POST /files/{id}/replace`, z atrapą Vercel Blob.

**Architecture:** Trzy apki Django (`files`, `sharing`, `uploads`) i wspólne helpery API w `apps/core/api.py`. Storage za `Protocol` z czterema metodami (`put_url`, `head`, `copy`, `delete`); atrapa trzyma bajty na dysku i wystawia `PUT /api/v1/_blob/<key>` podpisany przez `django.core.signing`. Widoki to zwykłe funkcje z `JsonResponse`, bez DRF.

**Tech Stack:** Django 5.2, Postgres, pytest-django, ruff, mypy strict. Wszystko w `apps/backend`.

**Spec:** `docs/superpowers/specs/2026-11-07-upload-design.md`

## Global Constraints

- Koperta odpowiedzi zawsze `{"data": ..., "errors": [...]}`; błąd globalny to `data: null` i jeden wpis `{"code", "message"}`.
- Kody i statusy dokładnie jak w spec 4.2: 401 `unauthenticated`, 422 `validation_failed`, per plik `unsupported_file_type` / `file_too_large` / `name_conflict` / `validation_failed`; replace 403 `forbidden`, 404 `not_found`, 413 `file_too_large`, 415 `unsupported_file_type`; complete 403, 404, 409 `upload_incomplete`, 410 `upload_expired`.
- `MAX_FILE_BYTES = 26214400`, upload ważny 15 minut, 1 do 100 plików na żądanie.
- Ścieżki bez końcowego ukośnika, pod `api/v1/`.
- Daty w JSON jako ISO 8601 z `Z`.
- Widoki API zwolnione z CSRF. Sesja Django jako logowanie.
- Komentarze i teksty bez długiej pauzy, półpauzy i interpunktu.
- `ruff check`, `ruff format --check`, `mypy .` (strict) i `makemigrations --check` czyste.

## Review Focus

1. `PUT /_blob` z ciałem większym niż zadeklarowane `size_bytes`, gdy `Content-Length` kłamie: plik nie może zostać; test w Task 5.
2. Nazwa z rozszerzeniem wielkimi literami (`RAPORT.PDF`) przechodzi jako `pdf`; test w Task 4.
3. Dwa pliki o tej samej nazwie w jednym `POST /uploads`: drugi dostaje `name_conflict`, nie wyjątek; test w Task 7.
4. Grantee z samym `view` woła `replace`: 403, nie 404; test w Task 9.
5. `complete` wołane dwa razy: 200 i ten sam plik, bez drugiego `File`; test w Task 8.
